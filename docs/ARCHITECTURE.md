## 1. System Topology (Single-Repo, Strict Module Boundaries)

To guarantee zero-friction Vercel deployment while maintaining rock-solid separation between the pure engine, browser UI, exported standalone HTML player, and Kiro MCP server, HyperCrypt uses a **clean single-package TypeScript architecture** with strict boundary rules enforced in `.kiro/steering/structure.md`:

## 2. Core Data Schema (`.hcstack.json` v1)

Every Stack—whether built-in, edited in Studio, generated by `hypercrypt-mcp`, saved locally, or embedded in an exported `.html` file—conforms to one strict versioned schema:

```ts
export const CARD_WIDTH = 512;
export const CARD_HEIGHT = 342;

export type VisualEffect =
  | 'none'
  | 'dissolve'
  | 'wipe left'
  | 'wipe right'
  | 'iris open'
  | 'barn door open';

export type ButtonStyle = 'roundrect' | 'shadow' | 'transparent' | 'checkbox';
export type FieldStyle = 'rectangle' | 'scrolling' | 'transparent';

export interface CardObjectBase {
  id: string;
  name: string;
  x: number;        // 0..512
  y: number;        // 0..342
  width: number;
  height: number;
  visible: boolean;
  script: string;   // Authentic HyperTalk handlers
}

export interface ButtonObject extends CardObjectBase {
  type: 'button';
  style: ButtonStyle;
  label: string;
  accent?: boolean;
  checked?: boolean;
}

export interface FieldObject extends CardObjectBase {
  type: 'field';
  style: FieldStyle;
  text: string;
  locked: boolean;  // true = static display; false = editable input
  fontSize?: number;
}

export type CardObject = ButtonObject | FieldObject;

export interface Card {
  id: string;
  name: string;
  script: string;           // Card-level handlers: on openCard, on closeCard
  bitmapRle: string;        // Compact RLE-encoded 512×342 1-bit monochrome layer ("" = blank)
  objects: CardObject[];
}

export interface Stack {
  schemaVersion: 1;
  id: string;
  title: string;
  author: string;
  description: string;
  defaultTheme?: 'classic' | 'kiroween';
  script: string;           // Stack-level shared handlers
  cards: Card[];
}
```

### Why 1-Bit RLE Bitmap (`bitmapRle`)?
- A raw 512×342 RGBA PNG can easily be 40–100 KB, whereas a 1-bit RLE string for typical 1987 pixel art / Atkinson dithered scenes compresses to **1–6 KB of clean ASCII text** inside JSON!
- Because it stores pure `0/1` bits (not baked RGB pixels), switching between **1987 Cream** and **Kiroween Dusk** instantaneously re-renders every pixel in the active theme's ink & paper colors!

## 3. Security & Sandbox Guarantees

1. **Zero `eval()` / `new Function()`**: HyperTalk is parsed into a typed AST (`ProgramNode -> HandlerNode -> StatementNode[]`) and walked by an explicit TypeScript interpreter.
2. **Deterministic Resource Budgets**:
   - `maxSteps = 10_000` AST statement evaluations per event invocation (throws clean `SandboxLimitError`, never freezes browser or MCP).
   - `maxCallDepth = 32` for nested/recursive custom handlers.
   - `maxWaitMs = 5_000` clamped per `wait` statement (and `0ms` fast-forward mode during headless MCP/unit test execution!).
3. **XSS-Safe Single-File Export**: Exported HTML embeds Stack JSON via safely escaped `<script type="application/json" id="hc-stack-data">` (escaping `</script>` sequences) and renders all text via `textContent`—never raw `innerHTML` injection.
